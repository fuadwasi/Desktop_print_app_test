Goal

Context

“MQTT Section”

Each profile row should include:

Profile Name
MQTT Connection Status (Connected / Disconnected)
Toggle Switch (Active / Inactive)
Edit Button
Delete Button



Actions:

✅ Delete removes the profile
✅ Toggle activates/deactivates the profile

Clicking Edit → Opens same form pre-filled with profile data

Form Fields:

API Configuration
MQTT Configuration

Actions:

✅ Test MQTT Connection button

Only active profiles should maintain MQTT connections

Behavior:

On profile activation:

Establish MQTT connection
Subscribe to relevant topics


On deactivation:

Disconnect MQTT


On app startup:

Automatically connect all active profiles

In Profile List Page
In Profile Edit Page
